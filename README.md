# Management Information Systems Practicum

This repository contains my coursework, practical exercises, notes, and web development implementations for the **Management Information Systems Practicum**.

The practicum covers fundamental concepts of website development, HTML, PHP, database integration, CSS, Laravel, Bootstrap, and web application integration with GitHub and Google Sheets.
